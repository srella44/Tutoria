# 0007 · Siempre tema claro

- **Estado:** aceptada
- **Fecha:** 2026-11-26

## Decisión

TUTOR-ia se muestra siempre en tema claro, aunque el dispositivo esté en modo oscuro. La barra lateral y las
cabeceras de sección pasan a fondo blanco; el logo usa letras azul noche.

## Motivo

Sergio no quiere fondos oscuros.
